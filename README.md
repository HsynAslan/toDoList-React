# To Do List React Project

Bu proje, React.js kullanarak geliştirilmiş basit bir "Yapılacaklar Listesi" (To-Do List) uygulamasıdır. Kullanıcılar, yapılacak görevleri ekleyebilir, tamamlayabilir ve silebilirler. Ayrıca, görevler tarayıcıda saklanarak, sayfa yenilendiğinde kaybolmaz.

## Özellikler

- Yapılacaklar ekleme, silme ve tamamlama.
- Tamamlanmış görevler üzerine çizgi çekilir.
- Responsive tasarım sayesinde tüm cihazlarda düzgün görünüm.
- Görevler tarayıcıda `localStorage` kullanılarak saklanır.
- Ücretsiz hosting: [todolistreacthsyn.netlify.app](https://todolistreacthsyn.netlify.app/)

## Teknolojiler

- React.js
- JavaScript
- CSS
- HTML

## Kurulum

Projeyi kendi bilgisayarınızda çalıştırmak için şu adımları izleyebilirsiniz:

### 1. Projeyi Kopyalayın

GitHub reposunu klonlayın veya zip dosyasını indirin.

```bash
git clone https://github.com/HsynAslan/toDoList-React.git
```

### 2. Gerekli Paketleri Yükleyin

Proje dizinine gidin ve gerekli tüm bağımlılıkları yüklemek için aşağıdaki komutu çalıştırın.

```bash
npm install
```

### 3. Projeyi Çalıştırın

Projeyi geliştirme modunda çalıştırmak için şu komutu kullanın:

```bash
npm start
```

Tarayıcıda, [http://localhost:3000](http://localhost:3000) adresine giderek uygulamayı görüntüleyebilirsiniz.
